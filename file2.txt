instruksi git dasar

git status = untuk cek apakah ada perubahan
git add . = untuk masukkin perubahan ke staging
git commit -m "comment" = untuk masukkin perubahan ke git final
git push . = untuk fix kan perubahan


git branch = untuk cek branch
git checkout *nama branch* = untuk pindah branch



tidak mengincludekan file

bikin file namanya .gitignore
tulis nama filenya


***upload ke github***

masuk ke folder

git add .

git commit -m "comment"

git remote add origin *link github* = masukkin link repo github

git remote -v = cek koneksi

git branch -M *nama branch nya* = pilih branch nya

 
git push -u origin *nama branch nya* = upload
